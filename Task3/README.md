# Task 3 — SQL Injection Scanner

A Python-based SQL Injection Scanner developed for the SyntexHub Cybersecurity Internship.

## Project
- **Project 1:** SQL Injection Scanner
- Tests URL parameters with common SQL Injection payloads.
- Detects common SQL error indicators.
- Generates a scan report with detected findings.
- Uses a local test server for safe and authorized testing.

## Technologies
- Python
- Requests

## Purpose
This project demonstrates basic cybersecurity automation, SQL Injection testing, HTTP requests, and response analysis.

> **Note:** The scanner is intended only for authorized testing and local lab environments.
